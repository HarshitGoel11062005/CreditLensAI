

# CreditLens AI

## AI-Based SME Credit Intelligence & Financial Risk Assessment System

CreditLens AI is an AI/ML-based financial intelligence platform designed to analyze SME financial behavior, assess credit risk, identify anomalies, and provide explainable financial insights.

## Main Features

- Credit Intelligence Score
- Financial Health Score
- Credit Risk Prediction
- Transaction Anomaly Detection
- Explainable AI
- AI Financial Risk Copilot
- Interactive Dashboard

## Technology

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- Streamlit
- Plotly
